Switched to `pnpm` for a few projects recently. It’s impressive.

Why:
- Hard links mean faster installs + less disk usage
- Strict mode helps avoid dependency hell
- Monorepo support is first-class

If you’ve hit perf walls with npm or Yarn, give pnpm a spin.
