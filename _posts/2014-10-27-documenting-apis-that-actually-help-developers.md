[ThoughtWorks Radar](https://www.thoughtworks.com/radar/tools/swagger) called out **Swagger** this quarter, and it lined up with what we were doing.

We'd written great APIs, but devs still struggled using them — because our docs were scattered and outdated.

Swagger (now OpenAPI) changed that:
- Docs as code
- Live testing via Swagger UI
- Clear contracts for consumers

![Swagger UI](https://miro.medium.com/v2/resize:fit:720/format:webp/1*tYZD3H5K9DbJ9Sbsj4lVtw.png)

Swagger UI

APIs should be usable without a meeting. Swagger made that possible.
