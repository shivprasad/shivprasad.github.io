A quick roundup of CLI tools that made my life better this quarter:

- `fzf`: fuzzy file finder that works inside Vim and shell
- `tldr`: community-maintained man pages with examples
- `bat`: syntax-highlighted `cat` with Git diff support
- `jq`: JSON parsing that saves hours

My shell has become a powerful IDE, debugger, and status monitor — all from the terminal.
