> People, [Wengo](http://wengo.fr/) (and [Disruptive Innovations](http://disruptive-innovations.com/) with it) is immensely happy and proud to release the first beta public version of the [WengoPhone exension for Firefox](http://openwengo.org/). It is available only for Windows for the time being because we just could not resist showing you what we achieved. But don't worry, the Linux and Mac OS X versions are in the pipe, and those of you spending hours on irc.mozilla.org have already met `jgi` in charge of that task. This extension will work only with version 1.5 and more recent of Firefox. It will not work with Firefox 1.0.x.
