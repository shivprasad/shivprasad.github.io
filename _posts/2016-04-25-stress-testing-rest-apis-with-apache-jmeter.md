JMeter is still my go-to tool for stress testing REST APIs.

Benefits:
- Thread group-based concurrency control
- CSV data sources for realistic simulations
- Easy visualizations and plugins

Sample usage:
- Simulate 500 concurrent users for POST requests
- Validate latency and error rates
